# Legacy

Ce dossier contient les éléments historiques de la version 1 du projet RPG_ESI07.

## Unity v1

Le dossier `unity-v1` contient l’ancien client Unity.

À partir de la refonte v2, Unity n’est plus le client principal du projet. Il est conservé pour :

- historique du projet ;
- référence technique ;
- consultation éventuelle ;
- expérimentation future non prioritaire.

La roadmap v2 est désormais centrée sur un client web Vue 3 / TypeScript et un backend serveur-autoritaire.
